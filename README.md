# GLOBAL FIT — K-푸드 수출 유망국가 추천 AI Agent (기획)

LOTTE AX Challenge 2026 · 롯데웰푸드 과제 · 2026.11.04 예선 제출

> 근거 검증형 K-푸드 수출 유망국가 추천 AI Agent

## 목적
수출 시장의 단순 규모뿐 아니라 제품 적합성, 시장 성장 가능성 및 진입 위험을 함께 검토해 롯데웰푸드의 수출 유망국가를 선별하는 서비스를 제안했습니다.

## 제안 구조
- UN Comtrade, KATI, World Bank 등 데이터 활용 계획
- 국가별 후보 평가 및 순위 산정
- LLM 오케스트레이터를 통한 정보 수집 및 해석
- Evidence Gate를 통한 근거 검증
- TOP 3 국가 카드와 추천 근거 제시
- 규제 및 시장 이벤트 추가 검토

## 결과
예선 기획안과 포트폴리오를 제출했으며 예선 탈락했습니다.

## 구현 범위
본 프로젝트는 **기획 제안이며 미구현**입니다. 위 구조는 설계 내용으로, 실제 API 연동이나 국가 추천 모델 성능 검증을 완료했다는 의미가 아닙니다.

## 담당 역할 및 AI 활용
문제 정의, 서비스 방향과 평가·검증 구조를 설계하고 생성형 AI를 활용해 자료 조사, 기획안 구체화 및 문서 검토를 진행했습니다.

## 저장소 범위
당시 제출 기록과 예선 포트폴리오에 근거한 요약입니다. 원본 포트폴리오에는 다른 프로젝트 경험도 포함되어 있으므로 이 저장소에서는 GLOBAL FIT 제안만 분리했습니다. 개인정보가 포함된 지원서 및 원본 제출 자료는 포함하지 않았습니다.
